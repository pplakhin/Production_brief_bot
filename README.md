# Бриф-бот для видеопродакшна

Telegram-бот собирает у клиента бриф на видеопроект и присылает ответы вам в личку.
Работает на вебхуках, размещается на Vercel, код хранится на GitHub. Сторонних библиотек нет.

## Что внутри

```
api/webhook.js   — сюда Telegram присылает сообщения
api/setup.js     — одноразовая привязка вебхука
api/cron.js      — раз в день напоминает тем, кто бросил бриф
lib/flow.js      — тексты и вопросы брифа (правьте здесь)
lib/bot.js       — логика бота
lib/store.js     — хранение ответов в Upstash Redis
lib/telegram.js  — запросы к Telegram
vercel.json      — расписание напоминаний (09:00 UTC = 12:00 МСК)
```

## Запуск

### 1. GitHub
Создайте новый репозиторий (можно приватный) и загрузите в него все файлы из этой папки.
Через сайт: Add file → Upload files → перетащите содержимое папки.

### 2. Vercel
1. vercel.com → Add New → Project → выберите репозиторий → Deploy.
   Первый запуск пройдёт без настроек, это нормально.
2. В проекте откройте вкладку **Storage** → Create → **Upstash for Redis** (бесплатный план) →
   подключите к этому проекту. Переменные `KV_REST_API_URL` и `KV_REST_API_TOKEN` добавятся сами.

### 3. Переменные окружения
Settings → Environment Variables:

| Имя | Значение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | токен от @BotFather |
| `WEBHOOK_SECRET` | придумайте строку из латиницы и цифр, например `brief2026secretKey` |
| `CRON_SECRET` | ещё одна придуманная строка |
| `CONTACT_USERNAME` | `pplakhin` — куда ведёт кнопка «Написать напрямую» |
| `ADMIN_CHAT_ID` | пока оставьте пустым, заполните на шаге 5 |

После этого: Deployments → у последнего деплоя три точки → **Redeploy**.

### 4. Привязать вебхук
Откройте в браузере:

```
https://<имя-проекта>.vercel.app/api/setup?key=<ваш WEBHOOK_SECRET>
```

В ответе должно быть `"ok": true`.

### 5. Указать, куда слать брифы
1. Напишите своему боту `/myid`, он ответит числом.
2. Вставьте это число в `ADMIN_CHAT_ID` и снова сделайте Redeploy.

Важно: бот может писать вам, только если вы хоть раз написали ему сами. Шаг с `/myid` это закрывает.

### 6. Проверка
Пройдите бриф сами от `/start` до конца. Бриф и референсы должны прийти вам в личку.

## Как менять бота

- Тексты, вопросы, варианты ответов — `lib/flow.js`. Изменили файл на GitHub, Vercel обновит бота сам.
- Время напоминания — `vercel.json`, поле `schedule` (время в UTC).

## Как устроено напоминание
Vercel на бесплатном плане запускает задачу раз в день. Поэтому напоминание приходит через 1–2 суток
после того, как клиент бросил бриф, и только один раз. Через 7 дней тишины бот перестаёт напоминать.

## Безопасность
Токен храните только в переменных Vercel, в код его не вписывайте.
Если токен где-то засветился, в @BotFather: `/revoke` → выберите бота → новый токен вставьте в `TELEGRAM_BOT_TOKEN` → Redeploy → снова откройте `/api/setup`.
