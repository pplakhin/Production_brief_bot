# Бриф-бот: контекст проекта

Telegram-бот собирает у клиента бриф на видеопроект и присылает ответы владельцу в личку.
Владелец — видеопродакшн (съёмка, монтаж, цвет, графика). Общение с владельцем — на русском.

## Стек
- Node.js без зависимостей, Vercel serverless functions, Telegram webhook (не polling).
- Состояние брифа — Upstash Redis через REST (`lib/store.js`), т.к. функции Vercel stateless.
- Напоминания — Vercel Cron раз в день (`vercel.json`, Hobby-план).
- Код на GitHub, деплой Vercel из репозитория.
- Локальный запуск — `npm run local` (`scripts/local.js`): getUpdates вместо вебхука, снимает вебхук;
  без ключей Upstash хранит состояние в памяти.

## Принятые решения
- Клиенту НЕ показываются цены, ставки и смета. Смету владелец присылает лично по контактам.
- Бот НЕ считает смету. Он присылает владельцу в личку (`ADMIN_CHAT_ID`) бриф сообщением и HTML-файлом
  (`lib/file.js`), плюс пересылает референсы.
- Клиента заранее спрашивают, прислать ли ему копию брифа файлом (последний вопрос); если да — тот же файл.
- Перед отправкой клиент видит сводку ответов: «Всё верно, отправить» или «Исправить ответ» (список вопросов).
  После исправления бот задаёт вопросы, которые стали нужны, и возвращается к сводке.
- На каждом вопросе, кроме первого, есть «⬅️ Назад». Ответы на вопросы, ставшие ненужными, стираются.
- Кнопки ответов синие (`style: 'primary'`): Telegram позволяет только синий, зелёный и красный, чёрного нет.
  В ряд ставится столько кнопок, чтобы текст не обрезался (`layout` в `lib/bot.js`).
- Старт: приветствие от Павла, кнопки «Заполнить бриф» и «Написать напрямую» (ведёт на t.me/pplakhin через `CONTACT_USERNAME`).
- Бюджет: только «До 100 000 ₽ / От 100 до 250 тыс. ₽ / От 250 тыс. ₽», без «Не знаю».
- Убраны вопросы: где будет показан ролик; декорации и реквизит.
- Брошенный бриф сохраняется, напоминание отправляется один раз (через 1–2 суток).

## Порядок вопросов (lib/flow.js)
Что снимаем (+ «Другое» → уточнение) → хронометраж → доп. версии → съёмочные дни → где снимаем
(+ кол-во локаций) → кто в кадре (+ кол-во спикеров) → дата съёмки → графика → субтитры →
дедлайн → бюджет → референсы → имя → компания → телефон → способ связи (+ почта) → копия брифа файлом →
сводка ответов.

## Правила
- Токен бота только в переменных окружения Vercel, никогда в коде или git.
- Тексты и вопросы меняются в `lib/flow.js`, логика — в `lib/bot.js`.
